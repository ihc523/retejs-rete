# Rete.js + React 示例使用说明

本项目实现了 Rete.js 框架的多个示例功能，包括：

## 功能特性

### 1. 基础节点类型
- **数字节点 (Number)**: 输出一个数字值
- **加法节点 (Add)**: 接收两个输入并输出它们的和
- **带控件的数字节点 (Number Control)**: 可以通过输入框控制数值的节点
- **字符串节点 (String)**: 输出一个字符串值

### 2. 高级功能
- **自定义插槽类型**: 不同类型的插槽以实现类型安全连接
- **节点连接验证**: 自定义连接验证逻辑
- **自定义节点渲染**: 自定义节点的外观和行为
- **历史插件**: 实现撤销/重做功能

### 3. 交互功能
- 节点拖拽移动
- 连接线创建和删除
- 节点选择和取消选择
- 实时数据编辑（数字和字符串节点）

## 界面操作

### 按钮功能
- **Export Data**: 将当前节点图的数据导出到浏览器控制台
- **Clear All**: 清空所有节点
- **Undo**: 撤销上一个操作
- **Redo**: 重做上一个操作

### 交互方式
- 拖拽节点以移动它们
- 点击工作区取消节点选择
- 在数字/字符串节点的输入框中直接修改值
- 连接节点以创建数据流

## 代码结构

### 组件实现
- `NumberComponent`: 基础数字节点
- `AddComponent`: 加法运算节点
- `NumberControlComponent`: 带输入控件的数字节点
- `StringComponent`: 字符串节点
- `HistoryPlugin`: 历史记录插件

### 事件处理
- `rendernode`: 自定义节点渲染
- `renderconnection`: 自定义连接线渲染
- `updateconnection`: 更新连接线
- `connectioncreate`: 连接创建前验证
- `connectioncreated`: 连接创建后处理

## 技术栈

- **Vite**: 构建工具
- **React**: UI 框架
- **Rete.js**: 节点编辑器框架
- **TypeScript**: 类型安全（通过 JS 实现）

## 扩展建议

要添加新节点类型，可以：
1. 创建新的组件类继承 `Component`
2. 实现 `builder` 方法定义节点的输入输出
3. 实现 `worker` 方法定义节点的处理逻辑
4. 在 `App.jsx` 中注册组件
5. 可选：自定义节点的渲染方式

要添加新插件，可以：
1. 创建插件类实现 `install` 方法
2. 在 `App.jsx` 中使用 `editor.use()` 安装插件
